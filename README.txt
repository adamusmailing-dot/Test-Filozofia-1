INSTALACJA PWA NA ANDROIDZIE
1. Rozpakuj ZIP i opublikuj zawartość folderu na hostingu HTTPS (np. GitHub Pages lub Netlify).
2. Otwórz adres aplikacji w Chrome na Androidzie.
3. W menu Chrome wybierz „Zainstaluj aplikację” lub „Dodaj do ekranu głównego”.
4. Po pierwszym otwarciu pliki zostaną zapisane do pamięci podręcznej; aplikacja będzie działać offline.

ZIP nie jest plikiem APK. PWA wymaga publikacji pod adresem HTTPS.
Funkcje: nauka z wyjaśnieniami, test z wynikiem, fiszki, dodawanie przedmiotów/sprawdzianów/pytań, import i eksport JSON. Dane są lokalne w przeglądarce; eksportuj kopię zapasową.
